Your new skill should be a separate, reusable agent skill called `DXF-to-3D-BIM`, designed to work independently but connect directly to your existing `Sketch-to-CAD` workflow.

I inspected both GitHub repositories. Your existing skill already has a useful foundation: structured floor-plan JSON, AIA-style CAD layers, uncertainty tracking, mandatory approval, geometric checks and visual QA. BIMCraft has a command-driven BIM engine, DXF import, IFC interoperability, and CLI/MCP interfaces.

The critical design decision is this: don't simply import a DXF and extrude its lines. The agent must interpret the 2D geometry, reconstruct walls and openings, create actual BIM elements, and verify that the resulting 3D model matches the approved floor plan.

Proposed two-skill pipeline

Sketch-to-CAD

Sketch → DXF + PNG + floor-plan-model.json

DXF-to-3D-BIM

Interpret → Reconstruct → Approve → Model → Validate

3D BIM deliverables

Native BIMCraft project + IFC + 3D views + QA report

One important technical detail from BIMCraft's source documentation: its command and model coordinates use millimetres, with X east, Y north and Z up. The agent prompt below explicitly accounts for this, along with the fact that imported DXF linework is not automatically equivalent to semantic BIM objects.

- Small drafting gaps
- Duplicate lines
- Overlapping segments

Avoid extending walls across legitimate openings.

Preserve intended wall junctions.

Use geometric tolerances appropriate to the input's drafting precision.

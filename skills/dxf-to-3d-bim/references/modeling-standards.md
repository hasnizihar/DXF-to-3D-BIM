# Architectural BIM Modeling Standards

1. **Elevation & Verticality**:
   * Ground floor starts at elevation `0.0 mm`.
   * Standard floor-to-floor height is `3000.0 mm`.
   * Exterior wall default thickness is `200.0 mm` (or `250.0 mm`).
   * Interior partition default thickness is `100.0 mm`.
2. **Openings**:
   * Standard door height is `2100.0 mm`; standard single door width is `900.0 mm`.
   * Standard window sill height is `900.0 mm`; standard window height is `1200.0 mm`.
   * Every opening must associate with a host wall. Floating doors or windows are prohibited.
3. **Slabs & Floors**:
   * Ground slab extends to the exterior face of outer perimeter walls.
   * Default slab thickness is `150.0 mm`.
4. **Structural Review Boundary**:
   * All structural sizing (beams, columns, foundation footings) generated by this skill is strictly conceptual and for spatial coordination only.
   * Do not represent generated models as approved for structural engineering or code compliance.

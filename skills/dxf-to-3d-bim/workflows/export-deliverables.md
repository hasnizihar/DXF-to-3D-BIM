# Workflow: Export Deliverables

## Purpose
Package and deliver all verified 3D BIM assets, visual previews, and validation summaries to the user.

## Deliverables Package
* Native project: `<project_name>.bimcraft`
* Industry standard IFC: `<project_name>.ifc`
* Visual plan preview: `<project_name>.png`
* Intermediate semantic model: `model.json`
* Validation report: `validation-report.json`

## Delivery Steps
1. Place all artifacts in the user-specified or timestamped output directory.
2. Present a clear markdown summary showing element counts, export file paths, and visual confirmation.
3. Explicitly state the engineering boundary: structural sizing is conceptual and requires licensed professional sign-off.
